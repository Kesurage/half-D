## What this told us

- Engine, FS, video (Mali-G57, GLES1), audio, touch: all work. Game folder
  detection: works. Only the three game code libraries failed to load.
- The engine requests `bin/libserver_android_arm64.so`,
  `bin/libclient_android_arm64.so` and `libmenu.so` — with the `lib` prefix
  (COM_GenerateCommonLibraryName). Our zip shipped the unprefixed names, so the
  FS lookup missed; the bare-name fallback searches the APK's lib dir and the
  APK carried no game libs. Fixed in v0.1.1: correct names + libs baked into the
  APK (see docs/PORTING_NOTES.md §7).
- `bfd42b7` in the version string = hash of CI's in-workspace git init of the
  vendored engine, not the upstream pin.
